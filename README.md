# Koperasi SMA (JAIM) Al-Asyraf
Sistem koperasi sekolah (POS, stok, inventori & akses, laporan). Kod ini BERASINGAN daripada app-smasra.

- Frontend statik: `index.html`, `koop.css`, `koop-core.js`, `koop-pages.js` (GitHub Pages, boleh di-embed dalam Google Sites).
- Backend: `Code-Koop.gs` (Google Apps Script Web App + Google Sheet Koperasi). URL Web App ada di pemalar `KP_API` dalam `koop-core.js`.
- Log masuk: emel + PIN (akaun diurus Admin App di Tetapan). Admin pertama: emel dalam `ADMIN_EMEL`, PIN awal 1234 (wajib tukar).
